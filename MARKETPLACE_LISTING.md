## 📖 Full Description

### 🧠 Stop Losing Your Train of Thought — Capture Development Thinking as It Happens

**The Problem:** You make dozens of decisions while coding — why you chose an approach, what you tried, what blocked you — but none of it survives past the PR. Context switching kills momentum, standup reports are guesswork, and onboarding new team members means repeating yourself endlessly.

**The Solution:** Git-Aware Dev Journal is an IDE-native journal that links every note to your Git context — commit hash, branch, and file position. Your development narrative builds itself as you code, so decisions, blockers, and insights are always recoverable.

---

### ✨ Key Features

#### 📝 Rich Entry Types
- **6 journal entry types:** Notes, Decisions, TODOs, Blockers, Insights, Questions
- Every entry automatically linked to the current commit, branch, and file position

#### 🔗 Deep Git Integration
- **Auto-capture** from conventional commits (`feat:`, `fix:`, `docs:`, `refactor:`, `test:`, `chore:`, `perf:`)
- **Branch narratives** — automatic story of your branch's development (read-only)
- **Git blame integration** — journal notes visible as an extra column in Git blame
- **Code hover context** — see "Why did I write this?" on hover

#### 🔍 Search & Timeline
- **Timeline view** with chronological overview, filtering, and full-text search
- Filter by author, branch, date range, and entry type (Pro)

#### 📊 Reporting (Pro)
- **Standup generator** — "What I did yesterday" in Markdown, plain text, or Slack format
- **PR/MR summary generator** — release notes grouped by type (features, fixes, chores)
- **Weekly summaries** for managers and leads

#### 🔄 Collaboration (Pro)
- **Cross-device sync** — notes follow you between machines
- **Team sharing** via shared `.dev-journal/` directory
- **Export** to Markdown, JSON, and CSV

#### 🏢 Enterprise
- **Audit trail** — who changed what, when
- **Compliance export** and custom retention policies
- **Admin dashboard** and SSO integration

### 🚀 Quick Start

1. **Install** the plugin from JetBrains Marketplace
2. **Open** any Git-tracked project
3. Press **Ctrl+Shift+J** to add your first journal entry
4. Find the **Dev Journal** tool window in the bottom panel
5. Configure settings at **Settings → Tools → Git-Aware Dev Journal**
6. Start committing — conventional commits are auto-captured!
