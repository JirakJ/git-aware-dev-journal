# Git-Aware Dev Journal — JetBrains Marketplace Listing

## Plugin Name
Git-Aware Dev Journal

## Tagline
Never lose the "why" behind your code — Git-linked development journaling.

## Short Description
Capture decisions, blockers, and insights as you code — automatically linked to commits, branches, and files. Generate standups and PR summaries instantly.

## Full Description

<p>
Ever looked at code and wondered <em>"Why was this written this way?"</em> Git blame tells you <strong>who</strong> and <strong>when</strong>, but never <strong>why</strong>. Git-Aware Dev Journal fills that gap by connecting your development notes directly to your Git history — no context switching, no separate tools, no lost knowledge.
</p>

<h3>Key Features</h3>
<ul>
  <li><strong>Git-Linked Notes</strong> — Every journal entry is automatically tied to the current commit, branch, and file position. Your notes travel with your code.</li>
  <li><strong>Smart Auto-Capture</strong> — Parses conventional commits (<code>feat:</code>, <code>fix:</code>, <code>docs:</code>, <code>refactor:</code>, <code>test:</code>, <code>chore:</code>, <code>perf:</code>) and creates journal entries automatically.</li>
  <li><strong>Rich Entry Types</strong> — Notes, decisions, TODOs, blockers, insights, and questions — each with its own icon and search filter.</li>
  <li><strong>Branch Narratives</strong> — Automatic, readable story of all work done on a branch — perfect for onboarding and handoffs.</li>
  <li><strong>Timeline View</strong> — Searchable, filterable Dev Journal tool window with full project history at a glance.</li>
  <li><strong>Git Blame Integration</strong> — Journal notes appear as an extra column in Git blame. Hover over any line to see the context behind it.</li>
  <li><strong>Code Hover Context</strong> — "Why did I write this?" answers appear on hover, right where you need them.</li>
  <li><strong>Standup Generator</strong> — One-click "What I did yesterday" reports in Markdown, plain text, or Slack-compatible format. <em>(Pro)</em></li>
  <li><strong>PR/MR Summary Generator</strong> — Auto-generate release notes grouped by type from your journal entries. <em>(Pro)</em></li>
  <li><strong>Cross-Device Sync</strong> — Your journal follows you across machines. <em>(Pro)</em></li>
  <li><strong>Team Sharing</strong> — Share notes via a committed <code>.dev-journal/</code> directory so the whole team benefits. <em>(Pro)</em></li>
  <li><strong>Advanced Search &amp; Filters</strong> — Filter by author, branch, date range, and entry type. <em>(Pro)</em></li>
  <li><strong>Export Options</strong> — Export to Markdown, JSON, or CSV. <em>(Pro)</em></li>
  <li><strong>Audit Trail</strong> — Full change tracking for compliance. <em>(Enterprise)</em></li>
  <li><strong>Compliance Export &amp; Admin Dashboard</strong> — Enterprise-grade governance. <em>(Enterprise)</em></li>
  <li><strong>SSO Integration &amp; Custom Retention Policies</strong> — Fits your organization's security requirements. <em>(Enterprise)</em></li>
</ul>

<h3>Getting Started</h3>
<ol>
  <li><strong>Install</strong> — Search "Git-Aware Dev Journal" in <em>Settings → Plugins → Marketplace</em> and click Install.</li>
  <li><strong>Add Your First Note</strong> — Press <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>J</kbd> anywhere in your code to create a journal entry linked to the current context.</li>
  <li><strong>Explore</strong> — Open the <em>Dev Journal</em> tool window to browse your timeline, filter entries, and generate reports.</li>
</ol>
